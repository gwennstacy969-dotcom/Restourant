# 🍽️ Catering 2W - Modern Web Application

Selamat datang di repository resmi untuk website **Catering 2W**! 
Website ini adalah platform pemesanan catering modern yang dirancang dengan antarmuka yang elegan, efek visual premium, dan pengalaman pengguna yang halus.

## ✨ Fitur Utama
- **Desain Premium:** Tampilan UI/UX modern dengan efek *Glassmorphism* dan palet warna hangat (terracotta & peach).
- **Efek Interaktif:** Animasi scroll, tombol bermagnet (magnetic buttons), efek kilap pada tombol, dan animasi 3D tilt.
- **Sistem Pemesanan Mudah:** Pop-up modal interaktif untuk pemesanan instan tanpa perlu pindah halaman.
- **Dark Mode:** Mendukung mode gelap (Dark Mode) untuk kenyamanan mata.
- **Responsif:** Tampilan yang menyesuaikan di berbagai ukuran layar (Mobile, Tablet, Desktop).
- **Fitur Pencarian:** Command Palette pintar (tekan `Ctrl+K`) untuk navigasi cepat.

## 🚀 Teknologi yang Digunakan
- **Frontend:** HTML5, CSS3 (Vanilla), JavaScript (Vanilla)
- **Animasi:** CSS Keyframes, Intersection Observer API
- **Efek Tambahan:** Canvas Confetti
